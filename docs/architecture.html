01 · Product idea

Summary with provenance

Instead of asking readers to trust a detached synopsis, Marginal preserves the relationship between every explanation and the exact source region that supports it.

Original paper

A layout-aware passage is highlighted directly over the rendered PDF page, retaining typography, figures, tables, and surrounding context.

The card explains the source in plain language, adds why it matters, and remains connected through a live beam calculated from both elements’ bounding boxes.

02 · Runtime

A real state graph

FastAPI creates one typed `PaperState` per upload. LangGraph runs nodes as state transitions, checkpoints every superstep, and follows conditional edges based on the plan and validation result.

PDF upload

FastAPI creates an isolated paper context and graph thread.

PyMuPDF node

Sections, coordinates, captions, and crops initialize shared state.

Gemini function call

Calls `plan_analysis` to choose section, vision, and repo branches.

Graph branches

Select, summarize, figures, and repository nodes update state.

Validate → finalize

Incomplete state receives one deterministic repair pass.

03 · StateGraph nodes

Explicit, inspectable transitions

The workflow is no longer a manual tool loop. Named nodes read and return shared state; conditional edges route expensive branches only when the plan requires them.

extract

Initializes layout-aware sections, visuals, metadata, and trace.

plan

Chooses relevant sections and optional branches with one Gemini call.

select_passages

Creates exact deterministic evidence work items.

summarize

Batches all pending explanations or follows the local path.

figures

Runs conditionally when useful visual candidates exist.

repository

Resolves explicit evidence before inference.

validate / repair

Checks invariants and performs at most one bounded repair.

finalize

Marks state complete and freezes the frontend contract.

05 · Guarantees

Designed around trust

State is checkpointed

`InMemorySaver` records each graph superstep under a paper-specific thread id, making transitions inspectable and resumable within the request lifecycle.

Confidence stays visible

Paper evidence is “found.” A model suggestion is always “inferred.”

Failure stays useful

Rate limits route through deterministic summarization, validation, and bounded repair instead of crashing the graph.
